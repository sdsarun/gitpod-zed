# Gitpod Dark — Zed Theme

A dark theme for [Zed](https://zed.dev) inspired by the Gitpod IDE aesthetic. Built for developers who love a clean, low-contrast dark environment with warm amber accents.

## Preview

> _Dark background · warm amber highlights · full syntax and terminal coverage_

| Element | Color |
|---|---|
| Background | `#12100c` |
| Editor Surface | `#292524` |
| Accent | `#ffb45b` (amber) |
| Text | `#d4d4d4` |

## Installation

### From the Zed Extension Store

1. Open Zed
2. Press `Cmd+Shift+P` and run **Extensions: Install Extension**
3. Search for **Gitpod Dark** and install

### Manual

1. Clone this repository:
   ```bash
   git clone https://github.com/sdsarun/gitpod-zed.git
   ```
2. In Zed, open the Command Palette (`Cmd+Shift+P`) and run **Extensions: Install Dev Extension**
3. Select the cloned directory

## Activating the Theme

1. Open the Command Palette (`Cmd+Shift+P`)
2. Run **Theme: Select Theme**
3. Choose **Gitpod Dark**

## Features

- 🌑 Deep dark background optimised for long coding sessions
- 🟠 Warm amber accent colors (`#ffb45b`)
- 🖥️ Full terminal ANSI color palette
- 🔤 Complete syntax highlighting for all supported languages
- 👥 Multi-cursor player colors
- 🔀 Git diff colors (added, modified, deleted, conflict)
- 📋 Status indicators (error, warning, info, success, hint)
